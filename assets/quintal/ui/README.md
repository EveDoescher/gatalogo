# Arte de interface do Quintal

Imagens fornecidas pela usuária, copiadas sem edição. `import_manifest.json` registra os nomes de origem, caminhos internos e SHA-256 dos 38 PNGs conferidos em 09/10/2026.

Esta pasta já está declarada em `pubspec.yaml`. Usar `QuintalArtwork` para carregamento e escala consistentes; não usar caminhos de Downloads no app.

| Asset novo | Uso |
|---|---|
| `action_rename.png` | Renomear o residente; lápis do botão Nome. |
| `action_play.png` | Brincar com o gato usando a varinha. |
| `action_trade.png` | Pagar/trocar produtos no Mercadinho. |
| `action_upgrade.png` | Melhorar ou ampliar um espaço. |

Os demais `action_*` representam ações; `racao_*` representa arte de refeições, sem definir receitas novas; imagens de ingredientes representam recursos existentes. A fonte de regras e quantidades continua sendo o catálogo da API.

Referências de jogos ficam em `docs/referencias/kingshot/`, fora do bundle de arte do jogo.
